- GitHub: [@hgeniee](https://github.com/hgeniee)

## 🧰 10주 동안 배운 것 중 가장 쓸모 있는 명령어 3가지

1. `git status` — 막힐 때 제일 먼저 칠 명령어. Git이 다음에 뭘 하면 되는지 거의 다 알려 준다.
2. `git log --oneline --graph --all` — 지금 내가 어디에 있고, 브랜치가 어떻게 갈라졌는지 한눈에 보인다.
3. `git pull upstream main` — 매주 첫 명령어. 협업은 "남의 변경을 자주 받아 오는 것"부터 시작한다.

## 💥 가장 기억에 남는 에러와 해결 방법

`! [rejected] main -> main (fetch first)` — 처음 보면 무섭지만, "다른 사람이 먼저 올린 게 있으니 받아서 합쳐 와"라는 뜻이다.
`git pull` → (충돌이 나면 해결) → `git push` 로 끝!
