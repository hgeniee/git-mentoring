- 충돌이 났을 때 `title.md` 에 보인 내용과, 어떻게 해결했는지:
  ```
  <<<<<<< HEAD
  제목: Git 놀이터
  =======
  제목: 나의 첫 Git 연습장
  >>>>>>> change-title
  ```
  main과 change-title 브랜치가 title.md의 같은 줄을 서로 다르게 고쳐서 충돌이 났습니다. 두 제목을 모두 남기기로 하고 `<<<<<<<`, `=======`, `>>>>>>>` 표시 줄을 지운 뒤, `git add title.md` → `git commit -m "Fix: title.md 충돌 해결"`로 merge를 마무리했습니다.
- git-mentoring에서 매주 `main` 에서 새 브랜치를 만드는 이유: `git switch -c`는 지금 있는 브랜치에서 갈라져 나오기 때문에, 지난주 브랜치에서 새 브랜치를 만들면 지난주 파일까지 PR에 딸려 갑니다. 원본과 같은 최신 main에서 브랜치를 만들어야 이번 주 과제 파일만 깔끔하게 PR로 보낼 수 있습니다.
- 이번 주 소감: 충돌이 처음엔 에러처럼 보여서 당황했는데, 표시 줄만 정리하고 add, commit 하면 된다는 걸 알고 나니 생각보다 어렵지 않았습니다. `--graph`로 브랜치가 갈라졌다가 합쳐지는 모습을 직접 보니 merge가 확실히 이해됐습니다.
