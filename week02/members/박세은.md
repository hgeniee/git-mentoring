- `git config --global --list` 로 확인한 설정:

  - init.defaultbranch: main
- 실습 폴더에서 `git init` 후 `git status` 첫 줄: On branch main
- `git init` 과 `git clone` 의 차이를 내 말로 설명하기: git init은 새로운 git 저장소를 생성하는 데 사용되며, .git 폴더를 생성한다. 이 저장소는 로컬에만 존재하며, 원격 저장소와 연결되지 않는다. 그러나 git clone은 이미 존재하는 git 저장소를 로컬에 복제하는 데 사용되며, 원격 저장소와 연결되어 저장소의 전체 히스토리를 포함한 디렉터리를 생성한다.
- PAT를 비밀번호처럼 다뤄야 하는 이유: PAT를 사용함으로써 사용자가 깃허브 리포지토리에 대한 권한이 있는 사람, 사용자가 가져야 하는 세분화된 리포지토리 액세스 유형에 대해 생각하도록 강제하고 취약한 암호가 사용될 가능성을 제거함으로써 플랫폼이 더 안전해질 가능성이 있어서
- 이번 주 소감: SSH 키 대신 PAT를 사용하는 게 좋은 이유에 대해 알아볼 기회가 되어서 유익한 시간이었다.
