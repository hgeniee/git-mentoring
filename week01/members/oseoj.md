- 오늘 배운 Git 명령어 3가지와 의미:
  1. `git add` : 변경한 파일을 다음 커밋에 포함할 대상으로 올리기 (스테이징)
  2. `git commit` : 스테이징한 변경 내용을 메시지와 함께 하나의 기록으로 저장하기
  3. `git push` : 내 컴퓨터(로컬)의 커밋을 원격 저장소(GitHub)로 올리기

- Fork와 Clone의 차이를 내 말로 설명하기:
  Fork는 GitHub에 있는 다른 사람의 프로젝트를 내 계정으로 복사하는 것이고, Clone은 Fork한 저장소를 내 컴퓨터로 가져와서 실제로 수정할 수 있도록 하는 것이다. 

- 이번 주 소감:
