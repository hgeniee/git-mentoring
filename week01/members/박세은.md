- 오늘 배운 Git 명령어 3가지와 의미:
  1. git diff : 최근 버전과 작업 폴더의 수정 파일 사이의 차이 출력
  2. git log : 커밋 내역 확인
  3. git add [파일명.확장자명] : [파일명.확장자명]을 스테이지에 올림
- Fork와 Clone의 차이를 내 말로 설명하기: git clone은 원격 저장소에서 로컬 저장소로 복사본을 만드는 데 사용되는 명령어인 반면, git fork는 git 자체의 명령어가 아닌 호스팅 서비스에서 제공되는 기능으로, 내 계정에 다른 사람 프로젝트 복사본을 생성하는 걸 의미합니다.
