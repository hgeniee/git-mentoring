- 오늘 배운 Git 명령어 3가지와 의미:
    - git add : 수정한 파일 중 커밋에 넣을 것을 골라 스테이징 영역에 올리는 것
    -  git commit : 스테이징된 변경 사항을 메시지와 함께 하나의 버전 기록으로 저장하는 것
    - git push : 로컬에 쌓인 커밋을 GitHub 원격 저장소로 업로드하는 것
- Fork와 Clone의 차이를 내 말로 설명하기: Fork는 다른 사람의 저장소를 내 GitHub 계정으로 통째로 복사해 오는 것이고, 이 작업은 GitHub 웹 안에서만 일어난다. Clone은 GitHub에 있는 저장소를 내 컴퓨터로 내려받아서 직접 수정할 수 있게 만드는 것이다. 원본 저장소에는 바로 push할 권한이 없으니까, Fork로 내 저장소를 만들고 → Clone해서 작업하고 → push한 다음 → 원본에 PR을 보내는 순서로 기여한다.
- 이번 주 소감: 평소엔 add, commit, push를 거의 습관처럼 쳤는데, 각 단계가 정확히 뭘 하는지 정리하고 나니까 훨씬 명확해졌어요. 처음으로 Fork부터 PR까지 직접 해 봐서 뿌듯했고, 다음엔 충돌 해결도 겁먹지 않고 해 보고 싶어요!
