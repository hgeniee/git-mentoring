# 이현진 (튜터 예시)

- GitHub ID: hgeniee
- 한 줄 자기소개: Git & GitHub 멘토링을 진행하는 튜터입니다. 함께 첫 오픈소스 기여를 해 봐요!
- 오늘 배운 Git 명령어 3가지와 의미:
  1. `git add` : 변경한 파일을 다음 커밋에 포함할 대상으로 올리기 (스테이징)
  2. `git commit` : 스테이징한 변경 내용을 메시지와 함께 하나의 기록으로 저장하기
  3. `git push` : 내 컴퓨터(로컬)의 커밋을 원격 저장소(GitHub)로 올리기
- Fork와 Clone의 차이를 내 말로 설명하기:
  Fork는 남의 GitHub 저장소를 **내 GitHub 계정으로** 복사하는 것이고 (GitHub 안에서 일어남),
  Clone은 GitHub에 있는 저장소를 **내 컴퓨터로** 내려받는 것이다.
  그래서 오픈소스에 기여할 때는 먼저 Fork로 내 저장소를 만든 뒤, 그 저장소를 Clone해서 작업한다.
