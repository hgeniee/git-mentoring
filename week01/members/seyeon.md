- 오늘 배운 Git 명령어 3가지와 의미:
  1. `git clone` : GitHub에 있는 저장소를 내 컴퓨터로 통째로 내려받기
  2. `git switch -c` : 새 브랜치를 만들고 바로 그 브랜치로 이동하기
  3. `git push` : 내 컴퓨터에 쌓은 커밋을 원격 저장소(GitHub)로 올리기
- Fork와 Clone의 차이를 내 말로 설명하기:
  Fork는 다른 사람의 저장소를 GitHub 안에서 내 계정으로 복사해 오는 것이고,
  Clone은 GitHub에 있는 저장소를 내 컴퓨터로 내려받는 것이다.
  원본 저장소에는 내가 직접 push 할 권한이 없으니, Fork로 내 저장소를 만든 다음 그걸 Clone해서 작업하고 PR로 원본에 반영을 요청한다.
