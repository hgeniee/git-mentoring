# 이현진 (튜터 예시)

- GitHub ID: hgeniee
- 내 프로필 주소: https://github.com/hgeniee
- 프로필 README에 쓴 Markdown 문법 (5가지 이상):
  1. 제목 (`#`, `##`) — 소개, About me, Contact 로 구역 나누기
  2. 인용 (`>`) — 맨 위 한 줄 소개
  3. 표 — 멘토링 주차별로 다룬 내용 정리
  4. 체크리스트 (`- [x]`) — 올해 목표
  5. 링크 (`[글자](주소)`) — 멘토링 저장소 연결
- 4주차(`git init` 후 연결)와 이번 주(`git clone`)의 차이:
  4주차에는 로컬에 먼저 저장소가 있어서 `git remote add origin` 으로 직접 연결하고 `push -u` 로 짝지어 줘야 했다.
  이번 주에는 GitHub에서 만든 저장소를 clone해서 `origin` 연결과 짝짓기가 이미 되어 있었고, 바로 `git push` 할 수 있었다.
- Markdown을 쓰면서 헷갈렸던 점:
  Enter를 한 번만 치면 줄이 이어 붙어 보이는 것. 문단을 나눌 때는 빈 줄을 넣어야 한다.
- 다른 멘티에게 추천하고 싶은 프로필 꾸미기 팁:

  | 팁 | 이유 |
  |---|---|
  | 이모지를 제목 앞에 하나씩 | 구역이 한눈에 들어옴 |
  | VS Code 미리보기(`Ctrl + Shift + V`) | push 전에 모양을 확인할 수 있음 |
  | 목표를 체크리스트로 | 나중에 `[x]` 로 바꾸는 재미가 있음 |
